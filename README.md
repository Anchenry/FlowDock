# 拾流 FlowDock

拾流 FlowDock 是一款基于 **aria2** 的 Windows 图形下载工具，支持批量添加链接、下载队列、暂停续传和实时日志，并提供 Zenodo 数据集文件导入功能。

## 主要功能

- **批量下载**：一次添加多个地址，每行一个，支持 HTTP、HTTPS 和 FTP。
- **队列管理**：可设置同时下载 1～16 个文件，超出数量的任务自动排队。
- **暂停与继续**：暂停任务后可重新加入队列；服务器支持时可断点续传。
- **实时日志**：选中任务，查看连接、进度、错误及校验日志。
- **Zenodo 导入**：输入记录页面、编号或 DOI，解析文件清单，勾选后加入下载队列。
- **完整性校验**：通过 Zenodo 导入的文件下载完成后，核对文件大小及公开摘要；校验不一致时显示失败。
- **偏好保存**：保留任务记录、上次使用的保存目录、并发数量和外观模式。
- **日间与夜间模式**：在设置中即时预览和切换主题。

## 运行环境

- Windows 64 位系统。
- 安装了 Tkinter 的 Python 3 环境。
- 软件目录内保留配套的 `aria2c.exe`。

当前版本通过 Python 启动，尚未打包为独立 EXE。

## 如何启动

双击软件目录中的 **“拾流 FlowDock”快捷方式**。

也可以使用 **`启动下载器.bat`** 启动。快捷方式依赖本机路径，移动软件目录后可能需要更新；启动脚本会从所在目录查找主程序。

## 普通下载

1. 点击右上角 **“＋ 新建下载”**。
2. 粘贴下载地址，每行一个。
3. 选择保存目录，默认沿用上次成功添加任务时的目录。
4. 点击 **“开始下载”**。
5. 在主面板查看进度，选中任务查看实时日志。

暂停后点击 **“开始 / 继续”**，任务会重新进入队尾，有空位时自动开始。

## 从 Zenodo 导入

1. 点击 **“导入 Zenodo”**。
2. 输入记录地址、数字编号或 DOI，例如 `https://zenodo.org/records/14727217`。
3. 点击 **“解析文件”**，查看文件名、大小和校验信息。
4. 勾选需要的文件，选择保存目录。
5. 点击 **“加入下载队列”**。

文件传输完成后会进入 **“校验中”** 状态。大文件的校验需要额外时间，可在日志中查看进度。若记录未提供摘要，软件会说明无法完成内容摘要校验。

## 设置

左侧底部的 **“设置”** 提供以下选项：

- **同时下载文件数**：可选 1～16，默认 3。
- **外观模式**：日间或夜间。

降低并发上限时，已经开始的下载继续运行，队列等待空位后再启动新任务。点击“保存设置”后，偏好在重启后保留。

## 常见问题

**为什么下载速度慢？**  
速度取决于网络链路、服务器带宽和服务端限制。增加并发数量不一定能提速。

**日志出现 HTTP 429 是什么意思？**  
表示服务器认为请求过多。应暂停部分任务、降低并发数量，稍后重试。

**出现 SSL/TLS 握手失败怎么办？**  
说明安全连接未能建立。需要检查网络、代理及站点连通性；增加重试或并发数量通常无法直接解决。

**关闭软件后能继续下载吗？**  
软件会保存任务记录并关闭下载引擎。再次启动后，未完成任务默认暂停，需手动点击继续；能否续传取决于服务器支持情况及本地续传文件是否完整。

**任务显示“状态暂未更新”怎么办？**  
说明界面暂时无法读取本机下载引擎的状态。引擎仍在运行时，软件会保留下载并自动尝试重连，可先观察日志。
